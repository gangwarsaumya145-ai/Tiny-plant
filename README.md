# Tiny-plant
A tiny interactive plant project.
🌱 Tiny Plant

Tiny Plant is a small interactive web project where you help a tiny plant grow!

 How it works

There are two buttons:

- 💧 Water — helps the plant grow leaves.
- ☀️ Sun — helps the plant grow into a tree.

The project uses simple interactions, emojis, and CSS styling to make the plant feel alive.

 Built With

- HTML
- CSS
- JavaScript
- VS Code

 Why I Made It

I wanted to make a really small project that was simple but still interactive. I used it to practice connecting HTML, CSS, and JavaScript and making buttons change what appears on the page.

 Files

- "index.html" — webpage structure
- "style.css" — styling and design
- "script.js" — button interactions

 What I Learned

While making Tiny Plant, I practiced:

- Using JavaScript with HTML buttons
- Changing elements on a webpage with JavaScript
- Styling buttons and page elements with CSS
- Organizing a small web project
